# Atom-loss tutorial

Requires the unified `rstim` CLI from this repository on PATH and Python 3.
Extract into a fresh directory, then run `sh run.sh`.
Envelope decoding is beta; this example covers one generated Mid-SWAP case.

Expected final output (after CLI status messages):
```
Decoded shots: 64
Loss patterns: 10
Logical errors: 0 / 64
```

Zero errors in this seeded smoke example do not establish a zero logical error rate.
