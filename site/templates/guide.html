Workspace overview

Crates by workflow boundary

The workspace is split around circuit production, detector-error-model data paths, decoder experiments, and CSS-code construction. The cards below name the crate that owns each boundary before the walkthroughs link to runnable examples.

rstim

Simulator crate and CLI for circuit parsing, sampling, detection, DEM extraction, SVG rendering, and QP101 export.

rsinter

Benchmark orchestration and decoder experiment harness for surface-code and BB-circuit comparison flows.

rmatching

Rust MWPM decoder entry point for detector-error-model workflows.

rbposd

BP-OSD decoder component used by the workspace comparison harnesses.

rilpqec

ILP-style decoder component used in comparison and reproduction flows.

qec-code and qec-ilp-core

CSS construction helpers, code-family exports, and ILP-backed distance checks used by exact and randomized distance-search workflows.

Operation Types

Type Purpose Core Fields
gate Generic quantum gate or measurement operation. gate, targets, controls, raw_targets
repeat Nested block that preserves repeated circuit structure. count, body
tick Explicit timing separator. type
qubit_coords Coordinate declaration for one or more qubits. coords, targets
shift_coords Coordinate offset marker. delta
detector Detector annotation over measurement record sources. coords, sources
observable_include Logical observable include annotation. index, sources
noise Noise or fault operator preserving raw targets. gate, params, raw_targets
annotation Human-readable stream annotation. kind, text
