Input

Commands that accept --in read stdin when the flag is omitted. Dataset commands use directories with a manifest and fixed artifact names.

Output

--format human|json controls command status output where offered. Artifact flags such as --out and --stats-out name separate files.

Errors

Global error formatting and each command’s structured error channel are listed from the executable contract above.
