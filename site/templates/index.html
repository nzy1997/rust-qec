Why rstim alongside Stim?

Stim already provides fast stabilizer-circuit simulation and detector error models. RustQEC develops rstim so simulation can work directly with this workspace’s Rust tools for code construction, atom-loss sampling, dataset export, and decoding.

rstim reads Stim-style circuits and carries the circuit-to-decoder workflow through one CLI or Rust application. Stim remains a reference for the overlapping behavior; see Performance & validation for comparisons on shared circuits.
