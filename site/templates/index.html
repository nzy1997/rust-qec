Quick start

From clone to first circuit

git clone https://github.com/nzy1997/rstim
cd rstim
cargo build --workspace
printf 'H 0\nREPEAT 2 {\n  M 0\n  DETECTOR rec[-1]\n  TICK\n}\n' | cargo run -p rstim --bin rstim -- stats

The last command prints circuit statistics such as num_qubits, num_measurements, and num_detectors. From there, the guide walks through sampling, DEM extraction, rendering, and decoder experiments.
