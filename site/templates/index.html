Atom loss

From atom-loss circuits to loss-aware decoding

Model atom loss alongside Pauli noise, preserve loss flags in sampled data, and use that information when decoding.

  1. Model the loss

    Generate Mid-SWAP memory circuits with operation and measurement loss, alongside Pauli noise.

  2. Keep the loss information

    Carry measurement values and loss flags together. Keep decoder inputs separate from the answers used to evaluate them.

  3. Decode with loss awareness

    Use envelope matching or exact MLE on supported circuits, accounting for loss when predicting logical outcomes.
