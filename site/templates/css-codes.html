Build and inspect a code

A Calderbank–Shor–Steane (CSS) code uses separate X and Z stabilizer checks. Its distance is the smallest weight of a logical operator that the checks cannot detect.

List the built-in codes with qec-code:

qec-code code css list

Inspect the Steane code:

qec-code code steane summary
name: steane
n: 7
stabilizer_rank: 6
k: 1

n counts physical qubits; k counts encoded logical qubits. Six independent stabilizer checks leave one logical qubit.

Compute an exact distance

Run an exact search on the small Steane code:

qec-code code steane distance
distance: 3
logical_class: XLike
witness: x=[1, 1, 0, 1, 0, 0, 0] z=[0, 0, 0, 0, 0, 0, 0] weight=3

XLike identifies an X-type logical operator. The witness lists its X and Z support; its weight counts non-identity qubits. The exact search finds weight 3 and rules out every smaller weight.

Reference results and larger searches

The small Steane example uses the default exact search. Integer linear programming (ILP) solves larger distance searches with an optional solver; random-window searches find candidate upper bounds and do not certify the exact distance. See qec-code code css-distance --help for inputs and solver options.
