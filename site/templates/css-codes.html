Run it

Build and inspect a code

Run from a configured repository checkout. These commands are not included in the two-binary native archive. list names available codes; show steane prints the selected code description.

cargo run -p qec-code --features cli --bin qec-code -- list
cargo run -p qec-code --features cli --bin qec-code -- show steane

Check the distance

Compute an exact distance

The built-in Steane code is small enough for the default exact search. The result includes a logical class and a weight-3 witness.

cargo run -p qec-code --features cli --bin qec-code -- code steane distance
distance: 3
logical_class: XLike
witness: x=[1, 1, 0, 1, 0, 0, 0] z=[0, 0, 0, 0, 0, 0, 0] weight=3

The witness proves that a weight-3 logical operator exists. Because this command completes an exact search, distance: 3 also certifies that no lower-weight logical operator exists.
