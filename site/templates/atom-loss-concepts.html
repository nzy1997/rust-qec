Two bits, different jobs

A lost atom has no measured value. Loss-visible records preserve that distinction with interleaved loss_flag,value_bit pairs.

ATOM SURVIVES

0, value

The value bit is the measurement outcome.

ATOM IS LOST

1, placeholder

The value is a placeholder. Changing it must not change the decoder’s prediction.

Treating a lost value as an ordinary 0 or 1 can produce misleading detector parities.

Separate prediction from scoring

  1. Sample once. Export public records and private answers together; their manifests share a dataset_id.
  2. Decode public data. The decoder reads the circuit and loss-visible rows, without access to answers or hidden input masks.
  3. Score privately. Compare logical predictions with answers.b8. Input masks are already accounted for; do not apply them again.

OPTIONAL SOLVER

Envelope MLE

envelope-mle requires the ilp feature or the official native archive. Maximum-likelihood estimation (MLE) finds the most likely fault configuration in the envelope model. It uses integer linear programming (ILP) and can take longer than matching.

Each decoder has circuit acceptance limits. Enabling a solver does not extend support to arbitrary loss circuits.

Support and failure behavior

Envelope matching is Beta unless publication verification succeeds within its declared Mid-SWAP scope. Its release evidence is not published and verified yet.

Envelope MLE is independently Beta unless publication verification succeeds. Its release evidence is not published and verified yet; it requires an ILP-capable build.

The MLE Supported promise is limited to four measured workload points:

DistanceRoundsLoss probabilityShots
320.0021,024 or 16,384
310.011,024 or 16,384

Other rates, sizes, batches and circuit families are outside that promise. Being outside the promise does not always mean rejection; hard input limits determine which jobs are rejected.

  • unsupported_circuit reports an input outside the decoder’s acceptance rules; it is not a logical prediction.
  • MLE’s --shot-timeout-ms limits each solve phase, not compilation or the batch. A timeout writes diagnostics without predictions.
  • When changing the circuit, recompute logical-X support and regenerate the public and private bundles together.
  • Count logical failures only for complete, successful runs.
Exact acceptance rules and regression controls

The executable matrix and MLE scope plan define each decoder’s acceptance rules. Matching accepts the pinned conventional fixture; MLE rejects it before producing output files. The d=5/r=15 Mid-SWAP MLE regression control does not extend the Supported scope.
