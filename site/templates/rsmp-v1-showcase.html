What it preserves

Measurements first. Decoder data on demand.

RSMP v1 archives every measurement result needed to reconstruct a sample. During unpack, rstim rebuilds the circuit-derived transform, recovers measurements losslessly, and derives all detector and observable outputs from the supplied circuit.

Lossless measurements

No measurement bit is dropped. The archive stores enough independent coordinates to reconstruct the original measurement stream.

Circuit-bound decode

Unpack and verify require the original circuit, not a DEM. The archive stores a circuit identity digest and transform dimensions, not a circuit replacement.

Explicit v1 limits

Sweep-bit circuits are unsupported. Archives are sequential and do not provide random shot access.

Why circuit knowledge helps

The reversible transform separates sparse syndromes from free coordinates.

measurements XOR noiseless reference detectors + free coordinates dense or sparse syndrome codec independent Zstandard frames

The decoder rebuilds the same selected-detector/free-measurement transform from the circuit, recombines those coordinates, and applies the noiseless reference to recover measurements before deriving detectors and logical observables.

Real CLI workflow

Sample, pack, verify, unpack.

The four-shot compatibility case below is a mechanics demonstration. It is too small to be compression evidence because fixed archive envelope overhead dominates tiny inputs.

Pack measurements

cargo run --locked -p rstim --bin rstim -- pack_samples \
  --circuit rstim/tests/fixtures/rsmp/v1/compat.stim \
  --shots 4 \
  --in rstim/tests/fixtures/rsmp/v1/compat-measurements.b8 \
  --in_format b8 \
  --out /tmp/compat.rsmp

Verify without outputs

cargo run --locked -p rstim --bin rstim -- unpack_samples \
  --circuit rstim/tests/fixtures/rsmp/v1/compat.stim \
  --in /tmp/compat.rsmp \
  --verify_only

Recover decoder inputs

cargo run --locked -p rstim --bin rstim -- unpack_samples \
  --circuit rstim/tests/fixtures/rsmp/v1/compat.stim \
  --in /tmp/compat.rsmp \
  --measurements_out /tmp/measurements.b8 \
  --measurements_out_format b8 \
  --detectors_out /tmp/detectors.01 \
  --detectors_out_format 01 \
  --obs_out /tmp/observables.01 \
  --obs_out_format 01

Evidence and caveats

Production-style corruption coverage, with one readiness caveat.

The committed evidence includes seven required semantic roles, 27 named corruption recipes, 491 generated truncation checks, eight generated bit flips, and one immutable two-block compatibility fixture covering sparse and dense codecs.

Caveat

The complete 19-command readiness suite passes in a clean exported checkout. An ordinary working tree can fail evidence validation when a different current target/release/rstim exists at the historical producer path. That is an existence-dependent, non-hermetic checker behavior, not a recomputation failure of the committed compression arithmetic.
