1. Install a native package

Validated runtime environments: Ubuntu 24.04 x86_64 and macOS 15 Apple silicon. Other platforms are outside the tested support matrix. Each archive contains rustqec and rstim.

Linux x86_64 archivemacOS arm64 archiveChecksums and release manifest

In a new terminal, use an empty working directory. This POSIX shell snippet selects the architecture, verifies the selected archive, and adds its binaries to this terminal's PATH. Keep this terminal open for the examples below.

set -eu
case "$(uname -s)-$(uname -m)" in
  Linux-x86_64) target=x86_64-unknown-linux-gnu ;;
  Darwin-arm64) target=aarch64-apple-darwin ;;
  *) echo "No validated native archive for this platform" >&2; exit 1 ;;
esac
base=https://github.com/nzy1997/rust-qec/releases/download/v0.2.1
archive="rustqec-v0.2.1-${target}.tar.gz"
curl -fLO "$base/$archive" -O "$base/SHA256SUMS" -O "$base/release-manifest.json"
awk -v archive="$archive" '$2 == archive { n++; record=$0 } END { if(n != 1) exit 1; print record }' SHA256SUMS > "$archive.sha256"
if command -v sha256sum >/dev/null; then
  sha256sum -c "$archive.sha256"
else
  shasum -a 256 -c "$archive.sha256"
fi
tar -xzf "$archive"
export PATH="$(pwd)/${archive%.tar.gz}/bin:$PATH"
rustqec capabilities --format json

Success: the checksum command reports OK and the capability JSON includes circuit.stats. If a checksum fails, stop and download a fresh archive.

Expected fields in result: instruction_count: 5, num_qubits: 1, num_measurements: 1, num_detectors: 1, num_observables: 1.

3. Sample and verify a detector event

rstim detect --in circuit.stim --shots 1 --out_format dets
rstim analyze_errors --in circuit.stim --out model.dem
cat model.dem
rstim sample_dem --in model.dem --shots 1 --out_format dets
shot D0 L0
error(1) D0 L0
shot D0 L0

The X error has probability 1. Both detector streams therefore contain D0 and logical observable L0. This small example verifies installation and the command path; it is not a numerical-performance benchmark.

Building from source

For a frozen source build, check out v0.2.1. Current development builds are tested with Rust 1.88.0 (MSRV) and stable on the two native targets above. Install Rust and the platform's native build dependencies before building.

Ubuntu 24.04 build prerequisites
sudo apt-get update
sudo apt-get install -y build-essential clang cmake libclang-dev pkg-config libfontconfig1-dev python3-venv
macOS 15 build prerequisites
xcode-select --install
brew install cmake fontconfig pkg-config python

Homebrew must already be installed.

git clone --branch v0.2.1 --depth 1 https://github.com/nzy1997/rust-qec.git
cd rust-qec
cargo build --locked --workspace
export PATH="$(pwd)/target/debug:$PATH"

You can now run the same circuit example. Benchmark workflows may additionally need Python dependencies; use the setup guide linked from each workflow. The development build guide describes test prerequisites.

Version and support boundaries

This website follows master; the installed quickstart above targets v0.2.1. Source links labeled development may describe later changes. The repository release does not make all eleven crates version 0.2.1. Check the release manifest or Cargo metadata when selecting a library dependency.

Atom-loss envelope decoding is beta; experimental benchmark workflows do not establish universal performance or publication readiness. Read the support and migration contract and evidence guide before applying results to another circuit.
