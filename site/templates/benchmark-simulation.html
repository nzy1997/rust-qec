Near-Clifford postselected counts

Frozen distillation and MSC-d5 comparisons, measured October 13–14, 2026; report published October 15.

The two original application circuits are distillation (magic-state distillation) and MSC-d5 injection/cultivation (distance 5, noise parameter p = 10-3). Each call attempts 1, 64 or 1,024 shots. Acceptance requires every raw detector to be zero; logical errors use the XOR of raw observable 0, without reference normalization. These are postselected-counts results, not full-record throughput or a comparison with Stim.

Every cell below shows Strict / Fused rstim speedup: peer warm latency / rstim warm latency. Values above 1 favor rstim; values below 1 favor the peer. Strict uses the default arithmetic policy; Fused is an explicit alternative. Clifft's default and active-width-scheduled paths and SymFT's compiled CPU path were tuned separately, then frozen before evaluation.

These are point estimates from 18 new process rounds, with seven warm observations of at least 50 ms per process. Each process contributes its median elapsed time per call; geometric means use matched round ratios. The repeat reuses all 18 peer tuning selections from the initial run without retuning. Compilation, preparation and first calls are separate. The linked CSV retains all 36 comparisons and their intervals; near-parity point estimates alone do not establish a win.

Outcome: one-shot point estimates favor rstim, while 64/1,024-shot counts remain slower than compiled SymFT. At 1,024 shots, rstim latency is approximately 2.99–3.18 times SymFT latency. Neither of the two measured optimization candidates established broad or 1,024-shot gains. The transition-memo candidate was correctness-reviewed but has no performance result.

All results are historical and revision-bound, not measurements of current master or today's peers. The recorded revisions below remain unchanged by the repository's subsequent history rewrite.

  • SymFT compiled CPU: 3f718e9e0c58b277a8fb506b4170863db5c3dbe6.

Host: OMEN Windows/Ubuntu WSL2; pinned CPU0; FP64; CPU execution without GPU; six threading environment variables set to one. The initial run retained 666 tuning, 30 functional and 648 evaluation workers; the independent repeat retained 648 evaluation workers in 18 new rounds. Initial and repeat results remain separate.

The bootstrap intervals are approximate; calibrated family-wise 95% coverage is not established. All failures and outliers remain retained. These two circuits do not cover the full workload suite, larger circuits or Tsim, and establish neither universal SOTA nor a memory advantage.
