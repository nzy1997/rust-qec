# Fixed-call lifecycle benchmark draft

Measure all 12 original MSC counts cells with public default and zero-cache factors, three roles and 12 balanced rounds. Retain 72 finite-validation streams, 864 timing streams, all 221184 calls and prefixes 1, 2, 4, 8, 16, 32, 64, 128, 256. Each cell uses every role permutation exactly twice. Baseline and control execute the same exact native binary. Seeds are fixed across roles and rounds; these are repeated timings of matched deterministic workloads, not independent random populations.

The sampling clock includes RNG initialization and public count extraction. The second clock adds compilation and sampler preparation. Each prefix includes the first call and has no warm-up or adaptive stop. Teardown is measured only after 256 calls and is never extrapolated to shorter prefixes. Cache-off means the whole public fallback route rather than an isolated cache kernel. Finite measurement records are from the uncached reference only; the Rust probe compares aggregate counts and 16 RNG continuation words.

It independently replays both library archives and the complete committed protocol/fixture/workflow archive, while checking a fixed protocol inventory and reviewed probe/lock hashes. Guard selection, working directory and captured build environment must match; every worker must name the original preparation binary and fixture exactly. Relocation after collection does not rewrite those original paths. The offline summary reports every predeclared paired comparison and identical-binary noise control. It makes no significance or universal-win claim.
