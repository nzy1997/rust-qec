# Affine counts source-pair regression guard

This separate fixed guard measures counts-workspace source changes on the original
pure surface d7/r7 and d9/r9 inputs. It has twelve native-counts cells: 1/64/1024
attempted shots per call in Strict and explicit Fused. The existing 36-cell
cdf_source_pair remains byte-for-byte unchanged. The public probe identifies the
native counts API; it does not emit whether an optional affine model was admitted.
Treat affine eligibility as fixture scope, not as a measured internal route.

Each exact source is built locked with Rust1.93.1 and native CPU code generation.
Six balanced rounds use baseline, candidate, and an identical baseline control;
each process records seven observations accumulating at least50ms. Compilation,
preparation, first nonempty counts-call cost and warm throughput stay separate.
Both source refs must be exact40character Git commits; the protocol checkout must
be clean before collection. Compare parent and production in separate cohorts,
record actual host/CPU affinity, and retain every cell/failure.

The finite phase compares native counts with each source's own structured records
and16 subsequent RNG words percall, then independently replays full emitted raw
measurement records and original annotations. It covers8192 attempts for each
exact call size. The probe asserts carry equality but does not emit literal carry
words. Mixed counts/flat/counts and additional63/65/129 seams remain separately
covered by candidate source tests; this matrix times only the declared three call
sizes. No arbitrary joint/rare-error/physical/SOTA certification is supplied.

The explicit synthetic240-event contract fixture fabricates toy binaries/process
receipts to test offline validation and resealed-corruption rejection. It is
never production performance evidence. Real historical schema fixtures retain
their original provenance and are used only for schema tests. All13 original
input/control files and original upstream license provenance remain retained.

Run test_contract.py normally and with python -O before collection. Then run
prepare.py --baseline-ref SHA --candidate-ref SHA --out PATH, run_retained.py
--preparation PATH --out OUTPUT --control CONTROL, and verify.py --seal BUNDLE
before verify.py BUNDLE --git-sources normally and with python -O.
On the separate affine protocol ref, the registered workflow
near-clifford-x86-application-counts.yml selects this guard with
cdf_source_pair=true and exact baseline_ref/candidate_ref. Its cdf-source-pair
job executes these twelve cells and uploads originals and partial failures.
The original ce58 protocol ref and original 36-cell directory remain unchanged.
