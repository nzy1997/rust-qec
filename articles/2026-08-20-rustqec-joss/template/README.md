# JOSS template and constraints

- Target venue: *Journal of Open Source Software* (JOSS), software paper.
- Official format: Markdown `paper.md` with YAML metadata and BibTeX.
- Author instructions: <https://joss.readthedocs.io/en/latest/paper.html>
- Submission requirements: <https://joss.readthedocs.io/en/latest/submitting.html>
- Accessed: 2026-08-20.

The current guidance requests 750--1750 words and requires sections covering
the summary, statement of need, state of the field, software design, research
impact, and AI usage. The JOSS paper must describe the software contribution;
new atom-loss performance results belong in the companion research paper.

JOSS supplies a document format rather than a separate downloadable template
archive. This directory records the official sources and the constraints used
for the draft.
